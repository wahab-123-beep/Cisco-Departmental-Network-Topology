# Cisco Departmental Network Topology

A Computer Networks lab project created using Cisco Packet Tracer. The project models a departmental network for an organization with Computer Science, HR, and Management departments.

## Project Overview

The accompanying project report describes a network with:
- Three departmental switches (S1, S2, and S3)
- Routers connecting the network
- PCs assigned to the departments
- A web server in the Management department
- VLANs for departmental network segmentation

The report also discusses routing, Network Address Translation (NAT), Access Control Lists (ACLs), and secure switch access. Check the Packet Tracer configuration to confirm which of these features are implemented and working in the simulation.

## Project Objectives

- Understand the role of switches in a network.
- Practice basic switch configuration.
- Create VLANs and assign switch interfaces.
- Configure passwords for switch access.
- Test connectivity between network devices.

## How to Open the Project

1. Install and open Cisco Packet Tracer.
2. Download `Cisco-Departmental-Network-Topology.pkt` from this repository.
3. Open the `.pkt` file in Packet Tracer.
4. Inspect the topology and device configurations.
5. Use suitable connectivity tests, such as `ping`, and relevant `show` commands to verify the configuration.

## Configuration and Verification

The project report includes examples of:
- Setting a switch hostname
- Configuring console and enable passwords
- Creating VLANs and assigning access ports
- Saving the switch configuration
- Verifying VLANs with `show vlan brief`
- Reviewing configuration with `show running-config`

Actual device configurations and test results should be verified in the `.pkt` simulation.
